# Rescate del Chile Chicuarote

Proyecto de conservación biocultural y economía circular desarrollado por Santuario Ajolote en Xochimilco. Conservar al ajolote implica conservar el territorio que lo sostiene, y conservar ese territorio requiere que las comunidades puedan vivir dignamente de él.

## Contenido

1. Resumen ejecutivo
2. Problemática: pérdida de chinampas y biodiversidad
3. Justificación: diversidad genética, conocimiento chinampero, biodiversidad
4. Relación con la conservación del ajolote
5. La semilla como patrimonio vivo
6. Evolución del proyecto (2024–2026+)
7. Modelo de economía circular
8. Impacto en cuatro dimensiones
